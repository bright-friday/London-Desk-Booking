# London Desk Booking

Welcome to the London Desk Booking project! This repository aims to provide a solution for booking desks in a shared office environment.

## Getting Started

Please follow the instructions below to set up your environment and start using the application.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bright-friday/London-Desk-Booking.git
   ```
2. Navigate to the project directory:
   ```bash
   cd London-Desk-Booking
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

To start the application, run:
```bash
npm start
```
